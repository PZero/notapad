## 7 · NLnet – testo per il modulo (non è un'email)
**Dove:** https://nlnet.nl/propose/ (open call generale; prossima scadenza probabile 3 gennaio 2027, da verificare su nlnet.nl)
**Project name:** notªpad: open, user-owned wearable voice capture with an open MCP server

```
Abstract
notªpad is an open-source wearable voice recorder (hardware, firmware, app and
server) designed so that users own their recordings and choose which AI, local
or remote, transcribes and organises them. Commercial devices in this category
lock audio into one vendor's cloud. notªpad instead exposes recordings through
an open Model Context Protocol (MCP) server, so any compatible assistant can be
plugged in, including fully local ones.

The hardware is complete and public (KiCad 10, nRF52840, 2 PDM microphones,
256 MB NAND, LC3 audio over Bluetooth LE). This proposal funds the software
phase:
1. Zephyr firmware: all-day LC3 recording, NAND storage, BLE sync, OTA updates,
   power management and safety features.
2. Android app (Flutter): pairing, sync, local storage, export.
3. Open MCP server: standard access to recordings and transcripts for any AI
   client, with a privacy-first default (local processing).
4. Documentation and reproducible build files so others can build and modify
   the device.

All output is released under open licences: MIT for software, CERN-OHL-S-2.0
for hardware.
Repository: https://github.com/PZero/notapad
```
